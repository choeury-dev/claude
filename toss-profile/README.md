# 효도 프사 (가칭)

6070 세대용 **프로필 사진 생성 토스 미니앱**(앱인토스 WebView).
카테고리를 고르고 → 사진을 고르거나 찍으면 → 얼굴은 그대로 두고 살짝 보정한 프로필 사진을 만들어 준다.

| 카테고리 | 만드는 사진 | 템플릿 |
|---|---|---|
| 여행 | 부모님 인기 여행지 합성 | 제주 유채꽃, 경주 불국사 단풍, 장가계, 다낭, 스위스 알프스 |
| 효도 | 용돈 케이크·생신상·카네이션 | 3종 |
| 명언 | 배경 사진 + 글귀 패널 (카톡 프사 예시 스타일) | 가을 한옥, 봄 벚꽃, 바다 일출 |
| 웃긴사진 | 7080 시대 사진 | 70년대 졸업사진, 80년대 디스코장, 옛날 다방 DJ, 80년대 가요무대 |

- 무료: 하루 2장 (한국 시간 자정에 초기화). 3장째부터 장당 500원 (토스 인앱결제).
- 무료 사진 저장: **보상형 광고 시청** 또는 **쿠팡 파트너스 링크 클릭** 후 저장. 결제한 사진은 바로 저장.
- 사진 검사: 해상도·밝기·흔들림(화면에서 계산) + 얼굴 수·정면·가림(서버에서 AI 판정). 불합격하면 이유를 알려 주고 "다른 사진 고르기 / 새로 찍기"로 안내.

## 실행

```bash
cd toss-profile
npm install
npm test                                    # 21개 테스트
ALLOW_UNVERIFIED_ORDERS=1 npm run server    # API (GEMINI_API_KEY 없으면 MOCK 모드)
npm run dev                                 # 화면 http://localhost:5173/?mock=1
npm run revenue                             # 수익성 시나리오 표
```

`.env.example` 참고. Gemini API 키는 **서버에만** 둔다 (미니앱 번들에 넣으면 누구나 꺼내 쓴다).
`ait build`(미니앱 번들 만들기)는 Node 24 이상이 필요하다 (`@apps-in-toss/ait-format` 요구사항).

## 구조

```
shared/templates.js  카테고리·템플릿·AI 프롬프트 ("얼굴 고정" 규칙 공통 적용)
shared/quality.js    사진 품질 측정·판정, 안내 문구
shared/quota.js      하루 무료 2장 / 유료 크레딧
shared/revenue.js    수익성 모델 (scripts/revenue.js 로 실행)
server/              node:http API — /api/quota, /api/check, /api/generate, /api/purchase/grant
src/platform.js      토스 SDK ↔ 브라우저 대체 구현 (사진·카메라·광고·결제·저장·사용자 키)
src/imaging.js       캔버스: 품질 측정, 압축, 명언 글귀 합성, 미리보기 워터마크
src/App.jsx          화면 (큰 글씨 19px, 버튼 높이 60px)
```

SDK 함수는 `@apps-in-toss/web-framework` 3.10.0 타입 정의를 직접 확인해서 썼다:
`Device.getPhotos`, `Device.openCamera`, `loadFullScreenAd`/`showFullScreenAd`(`userEarnedReward` 이벤트),
`IAP.createOneTimePurchaseOrder`(`processProductGrant`), `File.saveBase64`, `openURL`, `User.getAnonymousKey`.

**명언 글귀는 AI가 아니라 캔버스로 직접 그린다.** 이미지 모델은 한글을 틀리게 쓰는 경우가 많고, 글귀를 고칠 때마다 다시 생성하면 비용이 든다.

## 보완해야 할 자료 (사용자 확인 필요)

1. **4번째 예시 이미지** — Drive 폴더의 `KakaoTalk_20261101_220319299.png`(11MB)는 Drive 다운로드 한도(10MB)에 걸려 확인하지 못했다. 다른 3장(명언 7줄 글귀, 한가위 인사 + 한복 + 크루즈, AI 인물 사진)만 반영했다.
2. **부모님 인기 여행지 목록** — 지금 5곳은 임의로 고른 초안이다. 여행사 판매 순위나 설문 같은 근거 자료가 있으면 교체.
3. **명언 문구** — 예시의 "살아보니 이렇더라"류 글귀는 출처가 불분명하게 퍼진 글이라 그대로 쓰지 않고 새로 썼다. 쓸 문구 목록(저작권 확인된 것)을 주면 교체.
4. **배경 템플릿 사진/스타일 기준** — 템플릿마다 "이런 느낌" 예시 1장씩 있으면 프롬프트를 맞추기 쉽다. 명절 인사(추석·설) 템플릿도 예시처럼 추가할지 결정.
5. **용돈 케이크의 지폐 표현** — 한국은행 「화폐도안 이용기준」에 맞는지 확인 필요. 지금 프롬프트는 "도안이 보이지 않는 파스텔 종이돈"으로 요청한다.
6. **쿠팡 파트너스 정책** — "링크를 눌러야 저장" 구조가 파트너스 운영정책의 **클릭 유도/보상 제공 금지**에 걸릴 수 있다 (원문 미확인). 쿠팡 파트너스 고객센터에 서면 확인 필요. 걸리면 쿠팡 버튼을 빼고 광고만 남긴다.
7. **앱인토스 정책** — ① 외부 링크로 나가는 버튼이 검수 반려 사례가 있다 (사용자가 인지하지 못한 외부 이동). ② 인앱결제·광고 수수료율(2026-02-28 무료 프로모션 종료 후)이 공개 자료로 확인되지 않았다. 콘솔/채널톡으로 확인.
8. **얼굴 사진 = 민감할 수 있는 개인정보** — 사진을 서버에 저장하지 않는 구조(지금 코드도 저장 안 함)와, 외부 AI(Google)로 전송한다는 고지·동의 문구가 필요하다.
9. **실사용자 사진 샘플** — 6070 사용자 실제 폰 사진 20장 정도로 품질 기준값(흔들림 40 등)을 다시 맞춰야 한다. 지금 값은 예시 사진 1장을 흐리게 만들어 정한 것이다.

## 수익이 날까? → **지금 설계로는 적자일 가능성이 높다**

`npm run revenue` 결과 (DAU 1명·하루 기준, 단위 원):

| 시나리오 | 무료 1장 원가 | 무료 1장 수익 | DAU 1명/일 손익 | DAU 1,000명 × 30일 |
|---|---|---|---|---|
| 기본 (Flash, eCPM 2만 원) | 70 | 8.9 | **−86.5** | −259만 원 |
| 낙관 (eCPM 3만, 광고 수익 100% 개발자, 결제 5%, 결제 수수료 15%) | 70 | 16.6 | −61.7 | −185만 원 |
| 비관 (eCPM 1만, 다시 만들기 많음, 결제 1%) | 96.5 | 5.5 | −142.2 | −427만 원 |
| 고화질 모델 (Pro, $0.134/장) | 237.9 | 8.9 | −362.8 | −1,088만 원 |
| **개선안: 무료는 템플릿 합성(원가≈0), AI는 유료만** | 1 | 8.9 | **+23.8** | +71만 원 |

핵심 숫자:

- **AI 1회 생성 원가 ≈ 53원** = $0.039 × 1,360원. 다시 만들기 포함하면 받는 사진 1장당 ≈ 70원.
- **보상형 광고 1회 수익 ≈ 7~30원** (eCPM 1만~3만 원 가정). 무료 1장이 본전이 되려면 eCPM이 **약 16.7만 원**이어야 하는데, 한국 보상형 광고 벤치마크는 약 $21(≈2.9만 원)이다. 광고만으로는 AI 원가를 못 메운다.
- **500원 결제 1장 순수입 ≈ 318원** = 500 ÷ 1.1(부가세) × 0.7(수수료 30% 가정). 장당 약 248원 남는다.
- 무료 손실을 결제로 메우려면 **매일 이용자의 약 26%가 결제**해야 한다. 일반적인 앱 결제율(한 자릿수 %)보다 훨씬 높다.

그래서 권하는 수정안:

1. **무료 2장은 AI 생성 대신 "템플릿 합성"으로** — 미리 만든 배경(여행지·명언·7080 틀) 위에 사람만 오려 붙이고(배경 제거) 밝기·피부톤만 보정. 원가가 거의 0원이라 광고 수익이 그대로 남는다.
2. **AI 고품질 생성은 유료(500원)에만** — 결제 1장당 약 248원 이익.
3. 또는 무료를 하루 1장으로 줄이고, 광고를 **생성 전에** 보여 준다 (만들고 저장 안 하는 사람의 원가를 막음). 이것만으로는 여전히 적자이므로 1번과 함께 써야 한다.
4. 고화질(Pro) 모델은 500원으로도 장당 이익이 약 80원뿐이라 쓰지 않는다.
