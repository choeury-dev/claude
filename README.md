# 모더라 (Modeora)

잠금 화면에서 말로 기억하고 싶은 것을 남기면, **기록**과 **분류**를 한 번에 해 주는 메모 앱.

> "리무버. 케찹" → `살 것` 카테고리에 `리무버`, `케찹` 두 개가 들어간다.

## 진행 단계

| 단계 | 내용 | 상태 |
|---|---|---|
| 1 | 텍스트로 기록·분류·저장 테스트 (Node CLI) | ✅ |
| 2 | 모바일 앱: Expo(React Native), 같은 `src/engine.js` 재사용 | ✅ `app/` |
| 3 | 음성 인식 + 잠금 화면 진입 | 예정 |

## 2단계: 앱 실행하기 (`app/`)

내 컴퓨터에서 (Node.js 필요):

```bash
cd app
npm install
npx expo start
```

휴대폰에 **Expo Go** 앱을 설치하고, 터미널에 나온 QR 코드를 찍으면 바로 열린다 (컴퓨터와 휴대폰이 같은 Wi-Fi). 브라우저로 보려면 터미널에서 `w` 키.

- 앱 상태는 `app/lib/useModeora.js` 에서 관리하고, 분류는 루트의 `src/engine.js` 를 그대로 쓴다 (`app/metro.config.js` 가 `../src` 를 읽게 해 줌).
- 저장은 기기 안(AsyncStorage). 서버나 계정은 아직 없다.
- 화면: 카테고리 칩 필터, 미분류 추천 카드(한 번에 옮기기), 항목 체크(완료)·탭해서 옮기기/삭제, 카테고리 추가(끝맺음 말 지정).

## 1단계: 텍스트로 테스트하기

```bash
node src/cli.js          # 대화형. 문장을 치면 기록, /help 로 명령 보기
npm test                 # 분류 규칙 테스트
```

예시 세션:

```
> /cat 살 것
> 리무버. 케찹
  ✓ [살 것] 리무버   ← 단어 "리무버"
  ✓ [살 것] 케찹     ← 단어 "케찹"
> 치과 예약하기, 택배 보내기
  ✓ [미분류] 치과 예약하기  (추천: 할 일)   ← 표현 "하기"
> /accept 할 일          # 추천 카테고리를 만들고 한꺼번에 옮김
```

데이터는 `data/modeora.json` 에 저장된다 (`MODEORA_DB` 환경변수로 경로 변경).

### 한 문장을 나누는 방법 (`src/parse.js`)

- 마침표·쉼표·줄바꿈, `그리고`, `~이랑`, `~하고` 로 항목을 나눈다.
- 문장 끝의 트리거 문구(`살 것`, `사야 돼` …)는 떼어 내고 분류 단서로 쓴다.
- `여행 준비: 여권, 충전기` 처럼 쓰면 카테고리를 직접 지정한다 (없으면 만든다).

### 분류 우선순위 (`src/engine.js` → `classify`)

1. **명시** — `카테고리: 내용`
2. **사용자 트리거** — 등록한 카테고리의 트리거 문구 (`살 것`을 등록하면 `사야 돼`도 따라옴)
3. **학습한 단어** — 예전에 그 카테고리로 들어갔거나 사용자가 옮긴 단어
4. **내장 힌트** (`src/hints.js`) — 등록된 카테고리면 바로 넣고, 아니면 `미분류`로 두고 *추천 카테고리*만 붙인다
5. 단서가 없으면 `미분류`. `/move` 로 옮기면 그 단어를 학습한다.

### 저장 형식

메모는 항목 하나당 한 개이고, 같은 발화에서 나온 메모는 `captureId` 를 공유한다.

```json
{ "id": "m_…", "captureId": "cap_…", "text": "케찹", "raw": "리무버. 케찹",
  "categoryId": "cat_…", "suggestedCategory": null,
  "reason": "hint", "confidence": "medium", "source": "text", "done": false, "createdAt": "…" }
```

### 알려진 한계

- 내장 힌트 사전은 직접 고른 단어 목록이다 (살 것 211개). 사전에 없는 단어는 처음엔 `미분류`이고, 한 번 옮기면 학습된다.
- `우유랑 빵` 의 `~랑`, `~와/과` 는 나누지 않는다 (`사랑`, `사과` 같은 단어가 잘못 잘리기 때문).
- 띄어쓰기만 있는 문장("리무버 케찹")은 **낱말이 모두 아는 단어일 때만** 나눈다. "유기농 케찹"처럼 모르는 낱말이 섞이면 한 항목으로 둔다 (여러 낱말로 된 상품명이 잘리지 않게).
- 이미 같은 카테고리에 안 끝낸 같은 기록이 있으면 새로 넣지 않고 알려 준다. 앱은 [추가] 버튼, CLI는 `/again`.
