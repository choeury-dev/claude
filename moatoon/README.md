# 모아툰 작업실

회차 스크립트를 쓰면 표지·내용·마지막(요약) 페이지와 컷 나누기, 배경, 인물, 말풍선 배치 가이드를 만들어 주는 웹앱.
설치나 빌드 없이 브라우저에서 돌아간다 (HTML + JavaScript 모듈). 화면 구성은 디자인 편집 도구(왼쪽 아이콘 레일 + 도구 패널, 가운데 페이지, 오른쪽 레이어)를 참고했다.

## 실행

ES 모듈을 쓰기 때문에 `index.html`을 더블클릭하면 열리지 않는다. 로컬 서버로 연다.

```bash
cd moatoon
python3 -m http.server 8080      # 또는: npx serve .
# 브라우저에서 http://localhost:8080
npm test                         # 스크립트·맞춤법·배치·페이지·워터마크 테스트 (Node 18+)
```

## 화면

### 첫 화면: 회차 드라이브

- **내 드라이브(이 브라우저)**: 회차가 IndexedDB에 자동 저장된다. 카드에 첫 페이지 미리보기가 나온다. 복제·삭제.
- **Google 드라이브**: 폴더를 열어 회차 파일을 고른다.
  - 열 수 있는 파일: 구글 문서(텍스트로 읽음), `.txt`·`.md` 스크립트, 이 앱이 저장한 `.moatoon.json`.
  - 스크립트 파일을 열면 저장된 기본 설정으로 회차를 만들고, 편집 화면의 **드라이브에 저장**(Ctrl+S)을 누르면 같은 폴더에 `회차이름.moatoon.json`으로 저장한다. 다시 저장하면 그 파일을 덮어쓴다. 쓰인 업로드 이미지도 파일 안에 함께 들어가서 다른 컴퓨터에서 열어도 보인다.
- **레이아웃 보관함**: 등록한 표지·내용·마지막 페이지 레이아웃.

#### Google 드라이브 연결 준비 (한 번)

1. Google Cloud 콘솔에서 프로젝트를 만들고 **Google Drive API**를 사용 설정한다.
2. 사용자 인증 정보 → OAuth 클라이언트 ID → 유형 **웹 애플리케이션**.
3. 승인된 JavaScript 원본에 앱 주소(예: `http://localhost:8080`)를 넣는다.
4. 첫 화면 **연결 설정**(또는 Google 드라이브 탭)에 클라이언트 ID를 넣고 연결한다.

권한은 `drive.readonly`(스크립트 읽기)와 `drive.file`(이 앱이 만든 파일 저장)을 요청한다. 앱을 "테스트" 상태로 두면 테스트 사용자로 등록한 계정만 로그인할 수 있다.

### 편집 화면

| 왼쪽 탭 | 하는 일 |
|---|---|
| 스크립트 | 회차 스크립트 편집, 페이지 수 미리보기, **배치 가이드 만들기** |
| 레이아웃 | 지금 페이지에 레이아웃·컷 나누기 적용, 페이지 종류 바꾸기, **레이아웃으로 등록** |
| 요소 | 캐릭터(추가·삭제), 감정 10가지, 동작 10가지, 말풍선 5가지 |
| 텍스트 | 글 상자·요약 상자 추가, 제목·대화·독백 폰트 |
| 업로드 | 캐릭터·배경 이미지 올리기, 캐릭터별(감정별) 이미지 등록 |
| 배경 | 선 그림 배경 가이드, 업로드한 배경 이미지 |
| 대사 가이드 | 모든 페이지의 대사를 바로 고치고, 맞춤법·사실 확인 결과를 **적용** |
| AI 활용 | 캐릭터 이미지 활용 가이드 |
| 설정 | 크기, 컷, 질감 표현, 폰트, 워터마크·페이지 번호, 페이지 레이아웃 기본값, API 키 |

- 페이지는 세로로 이어서 보이고, 페이지 머리의 버튼으로 위·아래 이동, 복제, 레이아웃 등록, 삭제를 한다. 맨 아래에서 표지·내용·마지막 페이지를 추가한다.
- 재료를 끌어서 컷에 놓으면 다듬어서 적용된다(인물은 바닥선·빈자리, 말풍선은 가까운 인물에 꼬리를 달고 얼굴·다른 말풍선을 피함). 칩을 클릭하면 선택한 컷이나 인물에 적용된다.
- 인물·말풍선·글 상자를 선택하면 네 모서리 조절점으로 크기를 바꾼다(말풍선·글 상자는 Shift로 비율 유지). 더블클릭하면 바로 고친다.
- 오른쪽 레이어 패널에서 지금 페이지의 요소를 고르거나 지운다. 화면 폭이 1280px 이하면 레이어 패널은 숨겨진다.
- 실행 취소 Ctrl+Z, 다시 실행 Ctrl+Shift+Z(또는 Ctrl+Y), 삭제 Delete.
- **다운로드**: 페이지마다 캔버스 크기 그대로 PNG. 쓰인 글자만 Google Fonts에서 받아 이미지에 넣는다.

## 회차 스크립트 형식

```
제목: 커피 한 잔의 비밀
회차: 3화
부제: 민지의 수상한 친절

#1 카페, 아침
민지(기쁨): 오늘 커피는 내가 살게!
준호(속마음): 뭔가 수상한데…
(민지가 손을 흔든다)
내레이션: 그날 오후

[마지막]
- 커피를 사 주는 친구는 야근을 미리 알고 있다
요약: 보고서는 미리미리
마무리: 다음 화에서 만나요!
```

| 줄 | 들어가는 곳 |
|---|---|
| `제목:` `회차:` `부제:` | 표지 페이지 (제목이 있을 때만 표지를 만든다) |
| `#1 카페, 아침` | 새 장면(컷). 장소 낱말로 배경 가이드, `밤`·`저녁`·`새벽`이면 어둡게 |
| `이름(감정): 대사` | 대사. `(속마음)`은 생각 풍선, `(외침)`이나 `!!`는 외침, `(속삭임)`은 점선 |
| `(지문)` | 동작·감정을 찾아 그 인물에게 적용 |
| `내레이션:` | 컷 왼쪽 위 네모 상자 |
| `[마지막]` 다음 줄, `요약:` | 마지막 페이지 요약 목록 |
| `마무리:` | 마지막 페이지 인물의 말풍선 |

내용 페이지는 장면을 "페이지당 컷 수"(기본 4)씩 나눠 만든다. 내용 레이아웃을 등록해 두면 그 컷 수와 배치를 쓴다.

## 설정

설정은 회차마다 저장된다. **기본값으로 저장**을 누르면 새 회차와 Google 드라이브에서 연 스크립트에 그 설정을 쓴다.

- **질감 표현**: 깔끔, 펜, 연필, 크레용, 수채화, 마커. SVG 필터로 배경·인물·업로드 이미지에 입히고 글자에는 입히지 않는다. 연필·크레용·수채화는 페이지 전체에 옅은 종이 결을 깐다. PNG에도 그대로 들어간다. (붓 터치를 새로 그리는 것이 아니라 질감을 흉내 내는 필터다.)
- **가이드 인물 모양**: 업로드 이미지가 없는 캐릭터의 가이드 그림(2등신 SD, 심플 선화, 동글 콩).
- **워터마크·페이지 번호**: 3×3 위치 칸 + 가로·세로 여백, 크기, 투명도 슬라이더로 모든 페이지 같은 자리에 고정한다. 워터마크는 글자 또는 업로드한 로고 이미지. 페이지 번호 형식은 `1 / 5`, `1`, `01`, `- 1 -`. 각각 "표지에는 넣지 않기"를 고를 수 있다. 편집 화면에서 끌어 옮길 수 없다(고정).
- **페이지 레이아웃 기본값**: 표지·내용·마지막에 쓸 레이아웃. 페이지를 다듬은 뒤 **레이아웃으로 등록**하면 컷 위치와 글 상자 위치·글꼴·정렬이 페이지 크기에 대한 비율로 저장돼서 다른 캔버스 크기에도 쓸 수 있다. 인물과 대사는 저장하지 않고, 직접 넣은 자유 글(예: 계정 안내)은 문구까지 저장한다.

## 업로드 이미지와 AI 활용 가이드

- 이미지를 올려 **캐릭터 이미지로 등록**한다(감정별로 여러 장 가능). 등록하면 그 캐릭터가 나오는 모든 컷이 가이드 그림 대신 이미지를 쓰고, 스크립트의 감정에 맞는 이미지를 고른다.
- 컷으로 끌면 컷 배경 이미지가 된다(컷에 맞게 잘려 보임). 로고는 워터마크로 쓸 수 있다.
- 원본 이미지는 바꾸지 않는다. 자르기·반전·기울이기·외곽선 같은 처리는 보이는 방식만 바꾸는 설정으로 저장된다. 긴 변이 2000px보다 크면 저장할 때 줄인다.
- **AI 활용** 탭:
  - **Claude로 분석**: 이미지를 Claude(`claude-opus-5-5`)에 보내 캐릭터 특징, 꼭 지킬 것, 하지 말 것, 색 조합, 얼굴 위치, 활용 제안 4~6개, 배치 팁을 받는다. Claude는 이미지를 새로 그리지 않고, 앱이 할 수 있는 처리(전신·상반신·얼굴 자르기, 좌우 반전, ±12도 기울이기, 흰 외곽선, 그림자, 원형·둥근 배경 판)만 고르도록 했다. 그래서 비율·색·표정은 바뀌지 않는다.
  - **기본 제안(AI 없이)**: API 키 없이 이미지에서 주요 색만 뽑고 정해진 활용법 5가지를 붙인다.
  - 제안마다 **캐릭터 이미지로 추가**(업로드 탭에서 끌어 씀) 또는 **선택한 인물에 적용**.
  - 얼굴 위치를 알면 말풍선 꼬리가 얼굴 쪽을 가리키고, 말풍선이 얼굴을 덜 가린다.

## 그림 편집 (완성 그림 → 레이어 분리 → 표정 바꾸기 / 인물 빼기)

왼쪽 **그림 편집** 탭. 그림은 OpenAI 이미지 편집 API가 그리고, 위치 찾기는 Claude, 합성은 이 앱이 한다.

1. **그림 넣기**: 완성된 웹툰 그림을 올리면 테두리 없는 전체 컷 페이지가 생긴다(그림 비율이 캔버스와 다르면 가장자리가 잘린다).
2. **영역 고르기**: "Claude로 찾기"(Anthropic 키 필요)로 캐릭터·말풍선 상자를 자동으로 잡거나 직접 추가한다. 청록 = 레이어로 분리할 캐릭터, 주황 = 지울 곳(말풍선·글자). 상자는 끌고 모서리로 조절한다.
3. **레이어 분리하기** (OpenAI 호출: 배경 1번 + 캐릭터마다 1번)
   - 배경: 영역 안의 인물·말풍선을 지우고 주변에 맞게 채운다. **영역 밖은 원본 픽셀 그대로** 두고 영역 안만 AI 결과를 부드럽게 붙인다.
   - 캐릭터: AI에게 투명 배경으로 오려 달라고 해서 **윤곽만** 받고, 색·선은 원본 픽셀을 쓴다(설정에서 끌 수 있음).
4. **표정 바꾸기**: 캔버스에서 캐릭터 레이어를 클릭 → 도구 막대에서 캐릭터 지정 → 업로드 탭에 등록해 둔 표정 이미지 고르기. 기본은 **얼굴 부분만** 고치고 몸·손은 그대로 둔다. "이전 버전"으로 되돌릴 수 있다.
5. **인물 빼기**: 레이어를 페이지 밖으로 끌어내면 빠진다. 뒤 배경은 2단계에서 이미 채워져 있다.

- 모델·품질은 설정 탭 "AI 연결"에서 고른다. 기본은 `gpt-image-2.5-sunburst`, 품질 높음. (`gpt-image-1`은 2026-10-23 종료 — OpenAI 공식 OpenAPI 명세 기준)
- 요청 형식은 OpenAI 공식 OpenAPI 명세(`POST /v1/images/edits`: image/image[], mask, background, size, quality, b64_json 응답)를 따랐다. 실제 키로는 시험하지 못했고, 응답을 흉내 낸 모의 시험으로 위치 맞추기·합성만 확인했다. AI 결과 품질(질감이 원본과 얼마나 맞는지, 윤곽이 정확한지)은 실제로 써 보며 확인해야 한다.
- 호출마다 OpenAI 요금이 든다. 키는 이 브라우저에만 저장되고 브라우저에서 OpenAI로 바로 간다(혼자 쓰는 용도).

## 맞춤법·사실 확인의 범위

- **맞춤법 (`js/spell.js`)**: 인터넷 없이 도는 규칙 64개. 규칙에 없는 오류는 찾지 못한다.
- **사실 확인**: 규칙으로는 판단할 수 없어 연도·숫자·'최초' 같은 주장에 "사실 확인 필요"만 표시한다.
- **Claude로 검사 (선택)**: 맞춤법과 사실을 다시 보고 권장 문장을 준다. 웹 검색 없이 모델 지식으로만 판단한다.
- API 키는 브라우저 localStorage에 저장되고 요청은 브라우저에서 바로 간다(`dangerouslyAllowBrowser`). 혼자 쓰는 컴퓨터에서만 쓰고, 남에게 배포하려면 서버를 두고 키를 서버에 둬야 한다.

## 저장 위치

| 무엇 | 어디 |
|---|---|
| 회차, 업로드 이미지 | 브라우저 IndexedDB (`moatoon-studio`) |
| 기본 설정, 등록한 레이아웃, API 키, Google 클라이언트 ID | 브라우저 localStorage |
| Google 드라이브 회차 | `회차이름.moatoon.json` (설정·페이지·쓰인 이미지 포함) |

이전 버전(한 페이지)에서 작업하던 내용은 처음 열 때 "이전 작업" 회차로 옮겨진다.

## 한계

- 인물·배경 가이드 그림은 배치용이다. 업로드 이미지는 그대로 쓰고, 새 포즈나 표정을 그려 주지는 않는다.
- 터치 화면에서는 재료 끌어 놓기가 안 된다(HTML 드래그 앤 드롭). 컷을 선택하고 칩을 탭하면 적용된다.
- Google 드라이브 연결과 Claude 호출은 실제 계정·키로 시험하지 않았다(이 저장소의 자동 테스트는 화면 동작과 로직만 확인).
