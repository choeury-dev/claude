# 모아툰 작업실

장면 스크립트를 쓰면 컷 나누기, 대략적인 배경, 인물, 말풍선 배치 가이드를 만들어 주는 웹앱.
설치나 빌드 없이 브라우저에서 바로 돌아간다 (HTML + JavaScript 모듈).

## 실행

ES 모듈을 쓰기 때문에 `index.html`을 더블클릭하면 열리지 않는다. 로컬 서버로 연다.

```bash
cd moatoon
python3 -m http.server 8080      # 또는: npx serve .
# 브라우저에서 http://localhost:8080
npm test                         # 스크립트 해석·맞춤법·배치 테스트 (Node 18+)
```

작업 내용은 브라우저 localStorage에 자동 저장된다.

## 작업 순서

1. **기본 설정**: 캔버스 크기(인스타 4:5, 1:1, 스토리 9:16, 직접 입력), 레이아웃(장면 수에 맞춤, 세로 3·4컷, 2×2, 1-2-2, 2×3, 3×3), 그림체(2등신 SD, 심플 선화, 동글 콩), 제목/대화/독백 폰트와 크기, 여백.
2. **장면 스크립트**: 아래 형식으로 쓰고 "배치 가이드 만들기".
3. **배치·편집**: 왼쪽 재료를 끌어다 컷에 놓고, 가운데 대사 가이드에서 대사를 고친다.

### 스크립트 형식

```
제목: 커피 한 잔의 비밀
#1 카페, 아침
민지(기쁨): 오늘 커피는 내가 살게!
준호(속마음): 뭔가 수상한데…
(민지가 손을 흔든다)
내레이션: 그날 오후
```

| 줄 | 뜻 |
|---|---|
| `제목: …` | 맨 위 제목 칸 |
| `#1 카페, 아침` (`장면`, `씬`도 가능) | 새 컷. 카페·방·교실·사무실·거리·공원·바다·지하철·편의점 낱말로 배경 가이드를 고르고, `밤`·`저녁`·`새벽`이면 어둡게 칠함 |
| `이름(감정): 대사` | 대사. 처음 나온 이름은 캐릭터로 추가 |
| `(속마음)`·`(독백)`·`(생각)` | 생각 풍선 + 독백 폰트 |
| `(외침)`·`(버럭)` 또는 `!!`로 끝남 | 외침 풍선 |
| `(속삭임)`·`(작게)` | 점선 풍선 |
| `(지문)` | 동작(손 흔들기, 가리키기, 달리기, 앉기, 점프, 팔짱, 만세, 머리 긁기, 전화)과 감정을 찾아 그 인물에게 적용 |
| `내레이션: …` | 컷 왼쪽 위 네모 상자 |

## 편집 화면

- **재료(왼쪽)**: 캐릭터(+새 캐릭터), 감정 10가지, 동작 10가지, 말풍선 5가지, 폰트, 배경.
  - 끌어서 컷에 놓으면 "다듬어서" 적용된다. 인물은 바닥선에 세우고 다른 인물과 겹치지 않게 옆으로 밀고, 컷 가운데를 보도록 방향을 정한다. 말풍선은 가장 가까운 인물에게 꼬리를 달고, 얼굴·다른 말풍선을 피해 놓은 자리 근처 빈 곳으로 옮긴다.
  - 감정·동작은 인물 위에, 폰트는 말풍선 위에 놓는다. 칩을 클릭하면 선택한 컷이나 인물에 적용된다.
- **크기 조절**: 인물이나 말풍선을 선택하면 네 모서리에 손잡이가 생긴다. 손잡이를 끌면 반대쪽 모서리를 고정한 채 크기가 바뀐다.
  - 인물: 비율을 지키며 커지고 작아진다.
  - 말풍선: 가로·세로를 따로 바꿀 수 있다(Shift를 누르면 비율 유지). 정한 크기 안에 글을 맞춰 줄바꿈하고, 넘치면 글자만 작아진다. 컷 밖으로는 넘어가지 않는다. 도구 막대의 **자동 크기**를 누르면 글에 맞춘 크기로 돌아간다.
- **캔버스**: 끌어서 옮기기(Alt를 누른 채 놓으면 다듬지 않음), 말풍선 더블클릭으로 바로 고치기, 선택하면 위에 뜨는 도구 막대(감정·동작·반전·크기·꼬리 대상·풍선 종류·글꼴), Delete로 삭제, Ctrl+Z로 되돌리기.
- **대사 가이드**: 모든 대사를 컷별로 보여 주고 바로 고칠 수 있다. 맞춤법 검사 결과는 권장 문장과 이유를 보여 주고, **적용**을 누르면 대사에 들어간다.
- **이미지로 내보내기**: 캔버스 크기 그대로 PNG. 쓰인 글자만 Google Fonts에서 받아 이미지에 넣는다.

## 맞춤법·사실 확인의 범위

- **맞춤법 (`js/spell.js`)**: 인터넷 없이 도는 규칙 64개. 자주 틀리는 표기(살께→살게, 몇일→며칠, 어떻해→어떡해, 됬→됐, 안되→안 돼 등), 의존 명사 띄어쓰기(할 수, 할 때, 할 것), 외래어 표기(화이팅→파이팅, 메세지→메시지 등)를 고친다. 규칙에 없는 오류는 찾지 못한다. 뜻에 따라 맞을 수도 있는 것(바램, 일부로, 안돼)은 "뜻 확인"으로 표시한다.
- **사실 확인**: 규칙으로는 사실 여부를 판단할 수 없다. 연도·숫자·'최초'·'가장' 같은 주장이 있는 대사에 "사실 확인 필요"만 표시한다.
- **Claude로 검사 (선택)**: Anthropic API 키를 넣으면 Claude(`claude-opus-5-5`)가 맞춤법과 사실을 다시 보고 권장 문장을 준다. 웹 검색 없이 모델이 아는 지식으로만 판단하므로, 확실하지 않으면 "의심스러움/판단 근거 부족"으로 답하게 했다. 키는 브라우저 localStorage에 저장되고 요청은 브라우저에서 API로 바로 가므로(`dangerouslyAllowBrowser`), 혼자 쓰는 컴퓨터에서만 쓴다. 남에게 배포하려면 서버를 두고 키를 서버에 둬야 한다.

## 한계

- 인물과 배경은 배치용 가이드 그림이다. 완성 그림은 내보낸 PNG 위에 그리거나 다른 도구에서 덧그린다.
- 터치 화면에서는 재료 끌어 놓기가 안 된다(HTML 드래그 앤 드롭). 대신 컷을 선택하고 칩을 탭하면 적용된다.
